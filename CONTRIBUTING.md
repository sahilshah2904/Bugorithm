# Contributing

1. Read the [README](README.md) and [roadmap](docs/ROADMAP.md). Pick one milestone or change you can verify independently.
2. Branch from `main` with a descriptive name. Keep changes to the relevant component and document any new setup commands in that component's README.
3. Stage the intended files and run `python3 scripts/check_repo.py` from the repository root. Run the component checks listed in its README when available.
4. Open a pull request with the problem, the resulting behaviour, and the checks you ran. Update the [handoff](docs/HANDOFF.md) when the current milestone or next step changes. Update the [changelog](CHANGELOG.md) when the change affects users or setup.

Keep lecture materials, reference files, working notes, private grading fixtures, and credentials in ignored local paths or private storage. Commit original public lessons, prompts, sample inputs, and synthetic fixtures that contributors can use to verify behaviour.
