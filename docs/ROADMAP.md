# Roadmap

1. **Agree on the core loop.** Use untimed Python debugging challenges with stories and marked edits.
2. **Design the experience.** Review Home, Learn, and the workspace on desktop and phone.
3. **Set up the repository.** Establish the layout, contributor workflow, checks, and version history.
4. **Build the Python workspace.** Start with one challenge, two public examples, custom input, and draft recovery.
5. **Add submission grading.** Keep private tests on the judge, stop at the first failure, and return that input for retry.
6. **Complete the debugging loop.** Add random selection, progress, the fix walkthrough, and a full-page success celebration.
7. **Build Learn.** Prepare 15 recap lessons and three reusable execution visualizations.
8. **Write the launch challenges.** Prepare 10 original debugging stories with tests and explanations.
9. **Verify and launch.** Test the complete flow across desktop and phone, then publish the web app and connect the judge.
10. **Expand the content.** Grow the core lessons and challenges. Add a separate interview library with Fix and Build modes, starting with 100 references and expanding over time.
